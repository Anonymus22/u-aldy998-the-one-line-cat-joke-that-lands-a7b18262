A single original one-line joke about cats, written for the make.fun micro bounty
"The One-Line Cat Joke That Lands".

The joke: a cat that stares at the wall for an hour every night — and the creeping
suspicion that the ghost, not the cat, is the one who's scared.

`main.ts` (Node, stdlib only, fully deterministic) writes exactly that one line to
`/output/entry.txt`. Run it with `node main.ts`.
